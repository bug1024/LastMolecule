# 《最后的分子》战斗音频

## 编曲

由 `tools/gen_battle_music.py` 生成，纯程序合成，可随时重跑。

- **普通战斗**采用 134–148 BPM，第一小节就有底鼓、第二和第四拍的军鼓、踩镲和短音低音。每八小节变一次编制，依次建立节拍、展开主题、抬高八度进入全奏，再以半拍短暂回落。各阶段保留独立主题、主奏音色与律动。
- **Boss**采用 146–158 BPM，保留 7/8、10/8 等分组节拍。底鼓和太鼓标出分组重拍，上行铜管和短弓形成呼应。最终 Boss 在 3+3+2 律动上使用 LM-001 主题的大调变体。
- **三层分轨**同长同拍。紧张层加入切分踩镲、军鼓鬼音和短弓，高潮层加入更亮的铜管重音、太鼓和鼓花。关键音效出现时，背景音乐让出 3 dB。
- **登场和收束**各有短乐句。登场重音对准亮相，交还操作前淡出。整场 Boss 战获胜后播放 `boss_death`，普通战斗获胜后播放 `win`。

## 运行时

`GameAudio` 把三层装进一个 `AudioStreamSynchronized` 同步播放。战斗界面每帧报告战况，`GameAudio` 只在下一条小节线换层：进入一拍内到位，退出用两小节慢慢收。

标题和研发曲应用 −6.5 dB 的场景增益，战斗曲应用 −1 dB。紧张与高潮层分别再衰减 5 dB 和 7 dB，为换层时的重叠和音效留出峰值空间。场景增益与玩家的音量滑条叠加。

| 战况 | 触发 | 层 |
| --- | --- | --- |
| Normal | 默认 | 基础层 |
| Tension | 玩家生命 ≤30%、敌人蓄大招、剂量毒性 ≥75% | 基础 + 紧张 |
| Climax | Boss 半血以下或正在蓄力、普通战斗只剩不到 25% 总血量 | 基础 + 高潮 + 部分紧张 |
| 收束 | 整场胜利或失败 | 下一重拍收掉战斗曲，接独立乐句 |

打开暂停菜单时音乐停在原位，继续时从同一处淡入。小节长度和 Boss 分组重拍由生成器写入 `scripts/core/music_meta.gd`。

## 战斗音效

分子攻击分四层：预备 `mol_charge`、释放 `mol_release`、命中 `hit` / `hit_heavy`，命中音里带低频余韵。另有护盾形成 `shield_form`、片段联动 `synergy`、AI 激活 `ai_scan`、AI 失误 `ai_fail`、Boss 攻击预警 `boss_warn`、Boss 受击 `boss_hurt` 和 Boss 死亡 `boss_die`。

## 重新生成

```bash
~/.local/bin/uv run --with numpy python tools/gen_battle_music.py
```

只生成部分内容时加参数：`--music`（只生成音乐）、`--sfx`（只生成音效）、`--only=phase2`（只生成一首）。`tools/gen_audio.py` 全量运行时会在最后调用它。

## 外部授权音乐

程序合成的音色上限有限：弦乐、铜管和合唱都是加法合成近似。如果需要更真实的配器，可以按同样的结构委托或购买授权音乐：每首 32 小节无缝循环，基础、紧张、高潮三层分轨同长同拍，另配三段短乐句。文件放到 `assets/audio/music/` 并沿用相同命名，再在 `music_meta.gd` 里填写一小节的秒数，`GameAudio` 不用改动。
