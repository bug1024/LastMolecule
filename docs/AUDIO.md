# 《最后的分子》战斗音频

## 旧音源评估

用 `ffmpeg` 解码后做了三项客观测量：节拍周期性（谱通量自相关在 0.25–1 秒内的峰值）、每秒低频冲击数、每 4 秒响度的变异系数。

| 曲目 | 节拍周期性 | 低频冲击/秒 | 响度变化 |
| --- | --- | --- | --- |
| 旧 `preclinical` / `phase1` / `phase2` / `phase3` | 0.18–0.41 | 1.0–1.8 | 0.02–0.04 |
| 旧 `battle` / `boss` | 0.73 / 0.96 | 2.3–2.8 | 0.02–0.05 |
| 新普通战斗曲（5 首） | 0.62–0.86 | 2.0–2.4 | 0.11–0.16 |
| 新 Boss 曲（6 首，不规则拍号） | 0.35–0.58 | 1.9–2.4 | 0.10–0.19 |

四个研发阶段实际使用的旧战斗曲以铺底为主，16 小节里反复同一个两小节单元，没有段落起伏。这是编曲本身的问题，调响度或叠鼓都解决不了，所以重新编曲合成。旧 `battle` 和 `boss` 的节拍够稳，但同样没有段落变化，也一并重做。Boss 曲故意使用不规则拍号，自相关峰因此偏低，属于设计上的结果。

## 新的编曲规则

由 `tools/gen_battle_music.py` 生成，纯程序合成，可随时重跑。

- **普通战斗：** 118–128 BPM，32 小节分四段：A 起、B 推进、C 全奏、D 收束并回升，每 8 小节换一次编制。每首有自己的两小节主题动机，按和弦级数做调内模进，节奏型就是辨识点。配器是低频战术打击乐、短促弦乐跳弓、带滤波包络的战术低音和生物质感纹理。每个研发阶段的调、速度、主题、主奏音色、低音律动和纹理都不同。
- **Boss：** 独立编曲，使用 7/8、10/8 等不规则拍号和弗里几亚 / 三全音不协和。中段（第 17–24 小节）明显加码：冲击、太鼓滚奏、合唱、主题升八度。D 段改为沉重的半拍与三全音长音，最后回升。最终 Boss 把 LM-001 主题放进 3+3+2 的律动里。
- **三层分轨：** 基础、紧张、高潮三层同长同拍。紧张层是高把位颤弓加小二度或三全音、细胞钟表声的十六分音和心跳；高潮层是铜管重音、八度低音十六分、合唱长和弦和太鼓。
- **短乐句：** `boss_intro` 是 Boss 登场标识，`boss_death` 是 Boss 死亡收束，最后转到大三和弦；`win` 是普通战斗胜利。
- **给音效留空间：** 音乐在 1.5–5 kHz 的能量很低，关键音效出现时音乐还会再让出 3 dB。

## 运行时

`GameAudio` 把三层装进一个 `AudioStreamSynchronized` 同步播放。战斗界面每帧报告战况，`GameAudio` 只在下一条小节线换层：进入一拍内到位，退出用两小节慢慢收。

| 战况 | 触发 | 层 |
| --- | --- | --- |
| Normal | 默认 | 基础层 |
| Tension | 玩家生命 ≤30%、敌人蓄大招、剂量毒性 ≥75% | 基础 + 紧张 |
| Climax | Boss 半血以下或正在蓄力、普通战斗只剩不到 25% 总血量 | 基础 + 高潮 + 部分紧张 |
| Victory | 胜利 / Boss 死亡 / 失败 | 下一拍收掉战斗曲，接独立乐句 |

打开暂停菜单时音乐停在原位，三层仍然对齐；继续时从同一处淡入。小节长度由生成器写入 `scripts/core/music_meta.gd`。

## 战斗音效

分子攻击分四层：预备 `mol_charge`、释放 `mol_release`、命中 `hit` / `hit_heavy`，命中音里带低频余韵。另有护盾形成 `shield_form`、片段联动 `synergy`、AI 激活 `ai_scan`、AI 失误 `ai_fail`、Boss 攻击预警 `boss_warn`、Boss 受击 `boss_hurt` 和 Boss 死亡 `boss_die`。

## 重新生成

```bash
~/.local/bin/uv run --with numpy python tools/gen_battle_music.py
```

只生成部分内容时加参数：`--music`（只生成音乐）、`--sfx`（只生成音效）、`--only=phase2`（只生成一首）。`tools/gen_audio.py` 全量运行时会在最后调用它。

## 外部授权音乐

程序合成的音色上限有限：弦乐、铜管和合唱都是加法合成近似。如果需要更真实的配器，可以按同样的结构委托或购买授权音乐：每首 32 小节无缝循环，基础、紧张、高潮三层分轨同长同拍，另配三段短乐句。文件放到 `assets/audio/music/` 并沿用相同命名，再在 `music_meta.gd` 里填写一小节的秒数，`GameAudio` 不用改动。
