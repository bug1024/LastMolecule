# 《最后的分子》音频

## 背景音乐

背景音乐用 Suno 生成的 7 首原创曲目。WAV 原件不进仓库，放在 `~/Documents/musics/LM`。导入工具 `tools/import_suno_music.py` 把它们处理成 `assets/audio/music/bgm/` 下的 OGG，并生成 `scripts/core/music_tracks.gd`。

| 逻辑 ID | 原曲 | 文件 | 场景 |
| --- | --- | --- | --- |
| TITLE | LM3.wav | bgm_title.ogg | 首页 |
| MAP | LM4.wav | bgm_map.ogg | 研发地图 |
| LAB | LM5.wav | bgm_lab.ogg | 研发实验室（总览）、分子设计 / 修饰 |
| EVENT | LM6.wav | bgm_event.ogg | 随机事件、阶段关口决策 |
| BATTLE | LM1.wav | bgm_battle.ogg | 普通战斗（含精英） |
| BOSS | LM2.wav | bgm_boss.ogg | 阶段 Boss 战 |
| BOSS_FINAL | LM-001 主题 | boss_final.ogg + 两条分轨 | 最终 Boss 战 |
| ENDING | LM7.wav | bgm_ending.ogg | 获批上市、主线结局 |

页面只调用 `GameAudio.play("MAP")` 这样的逻辑 ID，不写文件路径。注册表是 `GameAudio.MUSIC`，存放听感参数；`MusicTracks.DATA` 由工具生成，存放文件、循环点和节拍。新曲文件缺失时退回旧的程序合成曲（`fallback`），只警告一次。

### 格式

7 首原曲的左右声道逐采样完全相同（双单声道），所以按单声道编码，没有伪造立体声。只做一次有损编码：WAV 直接编为 Vorbis（libvorbis，compression_level 0.42，约 q5.8）。7 首合计约 9 MB。

### 循环

工具先用频谱通量估出速度和节拍网格，再在节拍上找循环点。

- 循环起止点之间的距离是 16 拍（一个乐句）的整数倍。
- 用去均值后的逐帧 mel 频谱比较两点前后各一段的相似度。
- 限制接缝两侧的电平差在 1.5 dB 以内，避免跳回安静段时听起来像从头重放。

OGG 文件只保留到循环终点。最后一段和循环起点前的同长一段做等功率交叉淡化，并在 ±20 ms 内按波形相关对齐。Godot 播到文件末尾时跳回 `loop_offset`，前奏只在第一次进入时播放。

| 曲目 | 速度 | 处理 | 交叉淡化 | 接缝检查 |
| --- | --- | --- | --- | --- |
| BATTLE | 128 BPM | 前 10 s 只播一次，之后循环 80 小节（9.9–159.6 s） | 1 拍 | 电平差 0.6 dB |
| BOSS | 139 BPM | 从原曲约 46 s 的主体段进入并循环 56 小节（45.8–142.8 s） | 2 拍 | 电平差 0.3 dB，相似度偏低 |
| TITLE | 157 BPM | 前 38 s 前奏只播一次，之后循环 48 小节（38.2–111.6 s） | 1 拍 | 电平差 0.9 dB |
| MAP | 127 BPM | 循环 48 小节（7.2–98.1 s），结尾收束段不进循环 | 1 拍 | 电平差 2.0 dB |
| LAB | 148 BPM | 循环 32 小节（35.1–86.9 s） | 1 小节 | 电平差 1.0 dB，相似度偏低 |
| EVENT | 85 BPM | 找不到可靠循环点：整首播放，结尾烘焙 2 s 淡出，停顿 1.2 s 后从头淡入 | — | — |
| ENDING | 76 BPM | 前奏只播一次，之后循环 28 小节（16.8–105.6 s），结尾收束段不进循环 | 1 拍 | 电平差 1.6 dB |

所有接缝处的频谱突变都低于整曲自身帧间变化的第 93 百分位。BOSS 整首循环时，跳回开头会掉 9 dB（后段越来越响），所以改为循环中段。

### 响度

工具用 ffmpeg `ebur128` 测整首积分响度，再用固定增益统一到 −16 LUFS。没有压缩，也没有限幅，原曲的动态（LRA 2.4–8.7 LU）保持不变。增益后采样峰值超过 −1 dBFS 时少拉一点，目前只有 EVENT 少拉了 0.3 dB。

运行时增益叠在文件之上：

| ID | 增益 | 切入淡化 | 回来时续播 |
| --- | --- | --- | --- |
| TITLE | −3.0 dB | 1.2 s | 是 |
| MAP | −3.5 dB | 1.0 s | 是 |
| LAB | −4.0 dB | 1.0 s | 是 |
| EVENT | −3.5 dB | 0.8 s | 是 |
| BATTLE | −4.0 dB | 0.6 s | 否 |
| BOSS | −3.0 dB | 0.4 s（登场第三段） | 否 |
| BOSS_FINAL | −1.0 dB | 0.4 s（登场第三段） | 否 |
| ENDING | −2.5 dB | 1.5 s | 否 |

战斗曲给音效留出空间。阶段 Boss 曲提前一拍淡入，使循环主体的首拍接近手牌恢复时点。

## 运行时

- **交叉淡化：**两个音乐播放器做等功率交叉淡化（音量按 sin 曲线），同一时刻最多两层背景音乐加一段短乐句。快速 A → B → A 时，还在淡出的 A 会被直接拉回来，不重播；第三首插进来时，仍在淡出的那首直接停掉。
- **防重复与续播：**同一个 ID 重复请求什么都不做。离开 TITLE / MAP / LAB / EVENT 后两分钟内回来，从离开时的位置接着播。
- **研发界面：**`rd_ui.gd` 在地图、事件、分子编辑器、战斗显隐变化时，到帧末统一决定播放哪首，优先级是事件 > 分子编辑 > 地图 > 实验室。同一帧里"地图关上、战斗打开"只算一次。卡牌、奖励、暂停、设置、帮助这类子面板不参与判断。
- **暂停：**音乐和演出短音频停在原位置。暂停期间切进的新曲保持暂停，离开的可续播曲目保存位置。继续时淡入，从暂停菜单返回首页时由首页解除暂停。
- **音量：**主音量、音乐、音效三条总线加静音，保存在 `user://settings.cfg`（`audio/muted` 是新增项，旧设置文件默认不静音）。拖动音量条或切换静音时，总线音量平滑过渡（每秒最多变化 5 倍线性幅度），不会爆音。
- **战况：**Suno 曲目是单轨。最终 Boss 和启用兜底分轨的战斗按小节线切换紧张与高潮层。

## 场景生命周期

| 场景 | 音乐 |
| --- | --- |
| 启动 / 返回首页 | TITLE |
| 新局进入研发界面 | 有开局事件时先 EVENT，关闭后 LAB |
| 打开研发地图 | MAP；关闭回 LAB |
| 地图上进入事件 | EVENT；结束回 MAP |
| 分子设计 / 修饰 | LAB |
| 普通战斗 | 立即切到 BATTLE（0.6 s）；抽牌、出牌、结束回合、换战况都不重播 |
| Boss 战 | 见下节 |
| 战斗胜利 / 失败 | 下一拍收掉战斗曲，接 `win` / `boss_death` / `lose` 短乐句；点"继续"后回到当前页面的音乐 |
| 获批上市、主线结局 | ENDING |
| 项目终止、失败 | 场景音乐淡出，只留 `terminated` / `failed` 短乐句 |

## Boss 登场

旧的 `boss_intro` 乐句是 D–A–D–E–F♯ 的上行铜管，最后落在 G 大三和弦上，听感就是胜利号角。配合的 `boss_entrance` 音效也是上扫加金属铃声。两者都已从登场流程中移除（文件留作备份）。

现在的流程：

1. 进入 Boss 战时，场景音乐用 0.5 s 淡出。
2. 第一段（环境变暗、黑边压入）播放新的 `boss_threat` 音效。它约 2.1 s，组成如下：
   - 重击和下沉的次低频；
   - D2 / E♭2 / A♭2 低音簇（小二度加三全音），整体缓慢下滑约 0.7 个半音，带不规则颤动；
   - 0.6 s 处一记较弱的"第二下心跳"。

   它没有任何上行或大三和弦。这是音效，走 SFX 总线，和 Boss BGM 是两个独立资源。
3. Boss 落地时保留原来的 `boss_stomp`。
4. 第三段（黑边退去、界面回来）开始时，预警音效在 0.18 s 内淡出，Boss 曲在 0.4 s 内淡入。快进沿用这次交接，演出中断时预警也会淡出。最终 Boss 使用 LM-001 的分层主题。
5. Boss 进入半血、蓄力等阶段时不重播 BGM。击败 Boss 后在下一拍收掉 Boss 主题，接 `boss_death`。

`boss_threat` 由 `tools/gen_battle_music.py --only=boss_threat` 程序合成，是一个克制的过渡方案，需要人工试听确认。

## 战斗音效

分子攻击分四层：预备 `mol_charge`、释放 `mol_release`、命中 `hit` / `hit_heavy`，命中音里带低频余韵。另有：

- 护盾形成 `shield_form`、片段联动 `synergy`；
- AI 激活 `ai_scan`、AI 失误 `ai_fail`；
- Boss 攻击预警 `boss_warn`、Boss 登场 `boss_threat`、Boss 受击 `boss_hurt`、Boss 死亡 `boss_die`；
- 分子进化 `level_up`。

关键音效出现时，背景音乐短暂让出 3 dB。普通出牌、悬停不触发避让。同一个音效 40 ms 内重复触发只响一次，避免叠加过载。

## 重新生成

导入 Suno 配乐：

```bash
~/.local/bin/uv run --with numpy --with soundfile python tools/import_suno_music.py
```

可以把 WAV 目录作为第一个参数传入。循环点写在工具顶部的 `TRACKS` 表里，换曲时需要重新分析并填写。

Boss 登场音效与战斗音效：

```bash
~/.local/bin/uv run --with numpy python tools/gen_battle_music.py --only=boss_threat
```

旧的程序合成音乐（`title.ogg`、`lab.ogg`、各阶段的分层战斗曲等）保留在 `assets/audio/music/` 下作为兜底。确认新音乐稳定后可以删除；删除前要先把 `GameAudio.MUSIC` 里的 `fallback` 改掉。

## 待人工试听

- **BOSS、LAB 的循环接缝：**这两首的长循环自动相似度偏低，靠 2 拍 / 1 小节交叉淡化过渡。
- **EVENT 的结尾：**淡出加停顿重启是安全方案，原曲本身没有可靠的循环点。
- **`boss_threat` 的听感：**是否够危险、是否盖住 BOSS 主题的开头。
- **整体响度：**页面曲与战斗曲、音乐与音效的相对响度，目前按测量值设定。
