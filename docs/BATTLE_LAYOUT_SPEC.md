# 战斗场景构图与动态视觉规范（灰盒草案）

状态：已将本草案的空间预算、独立承托层、可见轮廓锚点与扇形手牌接入 Godot；仍需按实机截图审核美术整合质量。暂停以“更换贴图／增加装饰”作为战斗整合手段。本草案先验证可交互场景的空间关系，随后再约束模块化素材生产。此前截图不作为美术整合完成的依据。

交互验证页：[battle-layout.html](prototypes/battle-layout.html)。用浏览器打开，切换 1–3 个目标、0–10 张手牌、分子复杂度、画幅和命中姿态。当前为独立布局实验，不接入 Godot，也不改变战斗规则。

## 空间预算

以 1280×720 为基准，使用比例区间而非从概念图量取固定像素：

| 层 | 空间与锚点 | 约束 |
| --- | --- | --- |
| 全局信息 | 高度 0–8% | 项目／阶段在左，回合与 AI 在右；常态不铺长规则 |
| 背景 | 高度 8–58%，延续到承托层之后 | 中央低细节，轮廓背后保留明度差；无角色、无 UI、无常驻命中光 |
| 战场承托 | 高度约 48–60%，统一投影基线约 58% | 独立于远景，具备透视与接触阴影，悬浮距离可辨 |
| 主角 | 常态结构中心约 x26%，投影基线 y58% | 结构外接框按可用区域适配，改变片段不得改变视觉中心与投影归属 |
| 单体敌人 | 中心 x75%，最大约 34%宽、45%高 | 身体主剪影与深腔分开定义；锚点以身体承托点为准，不以 PNG 中点为准 |
| 多敌人 | 目标中心约 x60%、75%、90% | 随目标数量分配宽度，独立点击、意图和状态不可重叠；不平均压缩全部字体 |
| 局部状态 | 高度约 61–69% | 固定布局锚点，动作时不跟随身体冲刺；状态扩展需预留行高 |
| 操作层 | 高度约 71–100% | 独立、安静的阅读底层，卡牌不直接压在高细节前景上 |
| 手牌 | 横向约 19–81% | 0–10 张动态排列，数量增多先收间距；悬停抬升，不修改卡牌数值和排序 |
| 侧翼操作 | 左能量／抽牌，右结束回合／弃牌 | 固定安全区，卡牌旋转与悬停不得占用按钮点击区 |

以上数值是待验证的起点，不是已批准的实现参数。灰盒应先证明这些区域能协同，再决定素材细节。

## 五层职责

1. 背景层：环境气氛与方向引导，主要以低频大形表达远近。
2. 战场层：承托面、阴影与遮挡，定义站位和相对高度。
3. 角色层：结构、身体和姿态；支持独立动画与替换。
4. 特效层：作用起点、接触点、受光、命中及回弹，不能遮住关键操作。
5. UI 层：稳定布局、清晰文本和输入反馈，不依赖背景图中的装饰定位。

## 模块化素材契约

每个角色资源必须附：可见轮廓边界、结构／身体中心、承托点、作用发出点／结合点、朝向、默认显示尺度、受光方向和动作余量。透明图集格子的中心不是角色锚点。

动态分子保留程序驱动的结构连接。核心环、支链、端点的线宽、亮暗面与节点比例由统一规则控制；外接框随结构变化时，通过显示区域适配，不能随意缩小到失去识别。

背景、承托面、前景、角色与瞬时光效分别交付。角色常态贴图不烘焙爆炸、永久亮边或接触阴影；阴影与受光必须根据实际站位产生。

## 动态验证与验收

- 常态：1/2/3 敌人、空手/3/5/8/10 张牌、简单／复杂分子都能保持主次。
- 输入：悬停、选中、选目标、取消、无能量、结束回合提示不引起整体重排。
- 动作：蓄力、接近、接触、回弹各有方向；接触点对应身体位置，状态栏和手牌保持稳定。
- 极值：长名称、多状态、低生命、护盾大数、击败一个目标后仍有清楚空间关系。
- 适配：16:9 与 16:10 均检查；4:3 作为压力测试，若不支持应明确最小尺寸与留边规则。
- 观感：灰度与缩小图先能读出双方、距离和当前操作，再加入真实素材。

审核顺序：灰盒构图 → 低细节色块与共同光照 → 单套主体整合 → 动作与接触 → 多主体／多分子验证 → 卡牌和控件美术。每一步都以实时场景为依据，概念图只约束艺术气质。


## 本轮运行实现

- `BattleLayout` 统一预算站位、目标尺寸、状态行与手牌安全区；高度不足时优先保留文字与操作空间，承托线不机械固定为 58%。
- `BattleStage` 独立绘制低细节承托面、接触阴影、命中受光与操作区暗底。
- `CreatureView.visible_body_rect()` 与 `MoleculeView.visual_bounds()` 提供可见边界；宽扁角色按底部锚定，阴影及作用点以可见轮廓为准。
- 敌人身体位移不再带动状态栏；分子冲刺以实际作用端点接触目标腔体，命中后回位。
- `BattleContact` 表达有方向的轨迹、接触碎片和短暂暖光；不把动作光烘焙入常态素材。
- 自动几何检查覆盖 1024×640、1280×720、1280×800、1600×900 的 1–3 目标与 0/3/5/8/10 张手牌（含悬停）。实机工具增加真实出牌命中与手牌数量截屏。

这里的承托层仍采用简化绘制，目的是先建立稳定空间关系；不将该版本标记为最终美术验收通过。


## 聚焦打磨：主体、动作、威胁与轻量 HUD

保持现有风格与五层空间结构。主角展示区域宽度由 29% 调为 33.5%，单体目标宽度由 34% 调为 37.4%，中心由 75% 前移到 73%；多目标位置继续独立预算。高度受顶部安全区约束，不强制越界等比放大。

顶部取消独立标题品牌、回合牌匾与 AI 外框，只保留阶段／敌人名、回合、AI 倍率与细进度条；完整规则与 AI 档位、失误率保留在悬停。安全攻击次数以短提示显示；两侧功能控件用低装饰度底板。常态手牌降低 8% 亮度，悬停恢复强调。

攻击加入后倾蓄力、前倾冲刺、接触停顿与回弹，接触碎片和轨迹增强方向性。受击通过局部暖光、短促形变、边缘震颤和贴近接触点的延迟伤害数字表达；不把命中光常驻化。Boss 以轻微前倾与呼吸打破对称站姿，角色状态栏保持独立稳定。
