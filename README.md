# 最后的分子 · The Last Molecule

一款关于新药研发的 roguelike 卡牌策略游戏，用 Godot 4 制作。

你经营一家小药企。公司手里有一个潜力巨大、却反复失败而被搁置的分子 **LM-001**。现有的方法救不了它——你需要先用一个个普通项目积累经验与研究证据，最终带着这些积累重启它。

## 运行

使用 Godot 4.7 或更高版本导入 `project.godot`，按 F5 从标题界面启动；按 F6 运行 `main.tscn` 可直接开一局。默认窗口 1280×720，支持中文与英文。

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path .
```

## 设计理念

### 1. 卡组是你的研发能力，分子才是你的角色

研发新药，本质上是找到靶点、设计分子、把它做成药，最终攻克一种疾病、帮助更多的人。游戏围绕这条主线展开：

- **使命是攻克一种疾病**。公司第一次立项时选定要攻克的疾病：非小细胞肺癌（靶点 EGFR）、艾滋病（逆转录酶）或耐药细菌感染（DNA 旋转酶）。之后的每个项目，都是对抗它的一代新药。
- **分子要契合靶点的结合口袋**。口袋上有热点——铰链区喜欢芳环、后口袋喜欢疏水基团、溶剂区适合极性基团——也有放不下大基团的地方。同一个片段放在不同位点，效果完全不同；每个靶点的最优分子都不一样。
- **疾病会进化出耐药**。每一代药物获批，疾病就进化出真实存在过的耐药突变（EGFR T790M → C797S、逆转录酶 K103N → Y181C……），口袋随之改变，下一代分子要重新设计。可以沿用上一代的结构再改。
- **终点是人**。每一代获批药物会记下帮助了多少患者，并收进公司的分子谱系：一排小小的结构图，看得出分子是怎么一代代进化来的。最终项目 LM-001 就是攻克这种疾病的「最后的分子」。

标准新药项目从亲手设计候选分子开始。骨架上有 7 个带类型的位点（连接位是核心结构，另有环上取代位和末端位），往上放药物化学片段：氟原子、苯环、吗啉、羧酸……每个片段都有收益也有代价，相邻片段还会触发组合（亲脂与极性相邻改善溶解度、芳环堆积提升活性、片段太亲脂会带来心脏毒性警示）。

分子是「角色」，体现在四个地方：

- **属性改变每一场战斗**。2 是中性，≤1 有代价，≥3 有收益，≥5 收益更大：
  - **活性**：高了开局力量；太低开局虚弱。
  - **选择性**：高了打出的破绽更深；太低早期战斗会脱靶。
  - **稳定性**：高了中毒更强，甚至让敌人开局就中毒；太低中毒减弱，活性的力量减半。
  - **溶解度**：高了首回合多抽牌、多能量；太低临床策略卡更贵（制剂优化卡可抵消）。

  战场上站着的就是你的分子：哪项效果生效，给这项属性加分的片段就亮一下。
- **对手专攻它的结构弱点**。敌人是药物真正要闯的生物学关卡：靶点结合口袋、脱靶激酶、肝药酶、外排泵、hERG 通道、DNA 损伤、病变细胞、千人千面的患者群体。其中一些专找结构上的破绽——肝药酶攻击没被氟原子保护的代谢软点，hERG 通道抓亲脂片段，DNA 损伤利用未排除的毒性警示，每暴露一个，它的攻击就更重，被打中的片段会闪红。设计分子时就要想好它会在哪里被攻击。
- **组合给专属卡**。芳环堆积、亲脂—极性平衡、氟原子屏蔽代谢软点，每种组合成立时，对应的分子特性卡（「π-π 堆积」「极性平衡」「代谢屏蔽」）每场战斗都会出现在牌组里。
- **决定卡池**。奖励卡按分子的强项偏向：活性高多出攻击，稳定性高多出中毒，选择性高多出破绽，溶解度高多出抽牌和临床卡。契合的卡会标出「契合分子」。
- **每个阶段都在考它的短板**。临床前查毒性警示、一期查选择性、二期查活性、三期查稳定性加溶解度。通过了，Boss 开局带破绽；没通过，Boss 更强。

分子也会跟着项目成长。打赢精英和 Boss 可以三选一拿新片段；每个里程碑都能换一次取代基（耗时 1 个月），为下一阶段的考验做准备；核心结构（连接位）整个项目只能换一次，代价是疗效数据作废和一场验证试验。带**毒性警示**的片段是待验证的风险：没排除的警示会让终审安全线更严，可以在平台建设做毒理验证——结果可能是排除，也可能是确认。

于是同一副牌，配上高活性分子和高选择性分子，是两种完全不同的打法；开局时为了强项接受的短板，会在后面某个阶段回来找你。

### 2. 研发指标就是战斗属性

游戏不把「经营」和「战斗」做成两套系统，而是让同一组数字贯穿全局：

- **安全风险就是血量**：生命 = 100 − 安全风险。战斗中挨的打会变成项目的安全风险，普通战斗打完不回血，伤害会一直带到下一场、带到终审。
- **疗效就是力量**：项目疗效越高，战斗开局的力量越高；终审也要求疗效达标。
- **数据就是 AI 的燃料**：数据越多，AI 卡越强、越不容易失误。
- **时间就是资金**：每一步都要花几个月，满一年扣一次年度成本，竞品也在同时推进。

于是每一次出牌、每一条路线选择，都同时是一次研发决策。

### 3. 每个阶段都是一类真实的研发难题

候选化合物发现 → 临床前 → 一期 → 二期 → 三期 → 上市审评。每个阶段有自己的分支地图、敌人、Boss 和节奏：

| 阶段 | 体验 | Boss 机制 |
| --- | --- | --- |
| 发现 | 探索：研究与事件更多 | 活性悬崖：一回合攻击过多会反噬 |
| 临床前 | 排雷：战斗与关键难关更多 | 毒性风暴：持续中毒与周期重击 |
| 一期 | 生存：休整机会更多 | 剂量限制性毒性：加剂量让双方一起变强 |
| 二期 | 疗效验证 | 疾病进展：越拖越强，并往牌组塞入不良反应 |
| 三期 | 多中心管理 | 多中心试验：三个中心同时作战 |

每个阶段的奖励卡池也偏向不同类型的卡，让一局游戏里牌组自然地随研发进程演变。阶段结束是一次 **Go / No-Go**：继续推进，或主动止损——止损不是失败，它会保留更多数据与资金给下一个项目。

### 4. 项目不同，打法不同

立项时选择项目类型，同一副「哪张攻击高就拿哪张」的牌组不能在所有项目里都最好：

- **标准新药**：没有额外规则，用来熟悉流程。
- **高选择性项目**：选择性是命门——一回合攻击过多会脱靶反伤自己，但攻击带「破绽」的目标不受限制，鼓励先标记、再精准输出。
- **长期安全性项目**：慢性用药的风险会一点点累积——每进入新阶段残留风险上升，敌人也会随回合变强，一味防守会被拖垮。

特色项目在中期里程碑有一次专属决策（例如「继续优化选择性」还是「保留活性、带着风险进临床」），前期的选择会影响整个后半程。

### 5. 构筑围绕研发方法，而不是数值

五类卡牌对应五种研发手段：分子设计（输出）、实验验证（防护与数据）、临床策略（持续损伤与节奏）、AI 技术（数据驱动、可能失误）、流程建设（持续生效的能力）。它们组合出不同的套路：分子快攻、毒性控制、稳健防守、数据驱动、流程体系……查看牌库时会显示当前牌组偏向哪个套路。

**AI 不是一张更强的牌，而是一条成长线**：数据越好，AI 越可靠；数据不足时 AI 会失误，并往牌组里塞入「噪声数据」。数据驱动的打法需要公司的长期积累，是中后期才真正成型的路线。

### 6. 跨局积累的是方法，终点是一个明确的目标

每个项目无论成败，都会给公司留下数据，提升下一个项目的 AI 起点。项目获批（或在关键阶段之后主动终止）还会留下该类项目的**研究证据**，同一类证据只记第一次。

集齐两项证据，就能重启 LM-001。证据决定它能走哪条研究路线——提高选择性、提高稳定性，或者不做改造正面迎接——每条路线都解决一个老问题，也带来新的代价。LM-001 是最难的项目，最终 Boss 就是这颗分子本身。

主线有不同的结局：获批时按所走的路线讲述不同的故事；而在关键阶段之后主动停下、公开全部数据，则是「把答案留下」——证明一条路走不通，同样是科学的进步。结局画面会回顾**这家公司走过的路**：哪个项目带来了哪项证据、当时做了什么决定、最后选了哪条路线。

### 7. 信息先于操作

决策需要的信息，应该在决策之前就能看到：

- 地图和总览常驻显示**终审目标**，逐条列出疗效、安全风险、数据的当前值与差距。
- 选项卡片用颜色区分收益、代价与耗时，条件不满足时直接写明缺什么。
- 出攻击牌前就预告会不会触发反噬，以及是哪一种规则触发的。
- 卡牌在战斗手牌尺寸下文字也清晰可读，右键或长按可以查看完整说明。

### 8. 专业，但不艰涩

游戏保留真实的研发术语（选择性、剂量限制性毒性、Go / No-Go、患者分层……），同时用白话解释它们的意思，希望行业内外的玩家、大人和孩子都能玩懂。

## 视听风格

- **实验室微观世界**：场景与交互采用程序绘制，分子主视觉、敌人标本与卡牌插画使用独立美术素材。玩家是一只会随团队成长进化的烧瓶（小烧瓶 → 锥形瓶 → 反应装置 → 自动化工作站 → 智能实验室），会眨眼、受击、担心、开心和沮丧；敌人是细胞、毒云、晶体等研发难题的化身；LM-001 是贯穿标题、主界面与最终战的同一颗分子。
- **统一的视觉语言**：深色实验室背景；绿色代表推进与收益，蓝色代表数据与 AI，金色代表关键奖励，红色只用于伤害与危险。地图是六边形路线图，界面元素反复呼应分子结构。
- **编排过的主题旋律**：音乐与音效全部由 `tools/gen_audio.py` 程序合成，没有外部素材。LM-001 有一段固定的主题旋律，在标题、最终 Boss 战和主线结局中以不同的配器与调式出现。

```sh
/usr/bin/python3 tools/gen_audio.py              # 重新生成全部音乐与音效（需要 numpy 与 ffmpeg）
/usr/bin/python3 tools/gen_audio.py --music-only # 只重新生成音乐
```

## 内容与代码结构

游戏内容以数据驱动：新增卡牌、敌人、事件、项目类型，优先修改 `data/` 下的 JSON 与 `localization/translations.csv`，而不是改代码。

| 路径 | 内容 |
| --- | --- |
| `data/cards.json` | 卡牌、起始牌组、各阶段的奖励卡池偏向 |
| `data/enemies.json`、`encounters.json` | 敌人与 Boss、各阶段遭遇与战斗奖励 |
| `data/maps.json` | 地图结构与各阶段的节点风格 |
| `data/projects.json` | 项目类型、战斗规则、里程碑专属决策、LM-001 的研究路线 |
| `data/events.json`、`research_plans.json`、`rewards.json` | 随机事件、研究方案、研发能力 |
| `data/molecule.json` | 分子骨架位点、片段、组合规则、预设方案、阶段考验、毒理验证与修饰的代价 |
| `data/diseases.json` | 可攻克的疾病、靶点的各代耐药变体与结合口袋热点、患者数换算 |
| `data/company.json`、`competitors.json`、`player.json` | 公司成长与 AI 档位、竞品、研发团队等级 |

| 路径 | 职责 |
| --- | --- |
| `scripts/game.gd` | 一局的流程：地图节点、事件、奖励、里程碑、终审、证据与结局 |
| `scripts/battle_manager.gd`、`scripts/combat/` | 战斗规则（纯逻辑），每次操作输出事件列表供界面播放 |
| `scripts/project_state.gd`、`company.gd`、`competition.gd` | 项目状态、公司跨局积累、竞品格局 |
| `scripts/core/` | 项目类型、局内存档、设置、音频、场景切换 |
| `scripts/rd_ui.gd`、`scripts/ui/` | 研发总览、地图、战斗、弹窗与各页面（深色实验室主题与动态交互） |
| `localization/translations.csv` | 中英文文案 |

业务逻辑与界面分离：逻辑层通过信号通知界面，界面只把玩家的操作转发回逻辑层。

## 验证

首次检出或修改翻译后先导入资源，再运行回归测试（脚本运行时错误也会被判为失败）：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --editor --import --quit
tests/run.sh
```

平衡模拟用规则型机器人批量跑局，可按项目类型、偏向的套路、公司积累等条件对比获批率与每张卡的表现：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tests/run_tests.gd -- --sim=300 [--type=selective] [--build=poison] [--company-data=220]
```
